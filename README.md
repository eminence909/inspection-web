# ระบบตรวจห้องเรียนและเขตพื้นที่ (สภานักเรียน)

## ไฟล์
- `index.html` `app.js` — หน้าผู้ตรวจ (ไม่ต้องล็อกอิน) + ดูเวร
- `roster.html` — หน้าผู้จัดเวร (รหัสแยก, เริ่มต้น 5678)
- `admin.html` `admin.js` — แอดมิน (รหัสเริ่มต้น 1234)
- `criteria.js` `calc.js` `summary.js` `roster.js` `pdf.js` — เกณฑ์ สูตร สรุป เวร PDF
- `Code.gs` — หลังบ้าน Google Apps Script
- `config.js` — ใส่ URL ของ Web App
- `style.css`

## ติดตั้ง
1. สร้าง Google Sheet ใหม่ (ชื่ออะไรก็ได้) > ส่วนขยาย > Apps Script
2. วางโค้ดจาก `Code.gs` ทั้งหมด บันทึก
3. Deploy > การทำให้ใช้งานได้รายการใหม่ > ประเภท "เว็บแอป"
   - ดำเนินการในฐานะ: ฉัน
   - ผู้มีสิทธิ์เข้าถึง: ทุกคน
   - กดอนุญาตสิทธิ์ (รวม Drive สำหรับเก็บ PDF ล่าสุด)
4. คัดลอก URL ที่ลงท้าย `/exec` ไปใส่ใน `config.js`
5. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages
6. เปิด `admin.html` เข้าด้วยรหัส `1234` แล้วไปแท็บ "ตั้งค่า" เปลี่ยนรหัสทันที เพิ่มรายชื่อผู้ตรวจ เหตุผลที่ตรวจไม่ได้ และชื่อผู้ลงนาม
7. ชีตต่าง ๆ ถูกสร้างอัตโนมัติเมื่อเรียกใช้ครั้งแรก

หมายเหตุ: ถ้าแก้ `Code.gs` ภายหลัง ต้อง Deploy เวอร์ชันใหม่ (จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่)

## วิธีใช้ย่อ
- ผู้จัดเวร: `roster.html` วางรายชื่อจากชีตหรือพิมพ์เอง แล้วกดบันทึก
- ผู้ตรวจ: เลือกวันที่ > ตรวจห้อง/เขต > ชั้น (ชื่อเวรถูกติ๊กให้) > ห้อง > กรอก > ตรวจสอบ > ส่ง
- แอดมิน: แก้คะแนน ดูสถานะส่ง สรุปรายสัปดาห์/เดือน กด PDF (สรุปรายสัปดาห์/เดือนจะเก็บฉบับล่าสุดลง Google Drive ให้ด้วย)
- เปิดรอบสรุปรายเดือนใหม่: แท็บ "สรุปรายเดือน" > เลือกวันจันทร์เริ่มต้น > เปิดรอบ

## แม่แบบ PDF
PDF ใบรายวัน/สรุปรายสัปดาห์/สรุปรายเดือน ใช้รูปใบประเมินเดิมในโฟลเดอร์ `tpl/` เป็นพื้น แล้ววางคะแนนและชื่อผู้ตรวจลงตามช่อง (ต้องอัปโหลดโฟลเดอร์ `tpl/` ขึ้น GitHub ด้วย)
